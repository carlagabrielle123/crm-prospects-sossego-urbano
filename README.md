# CRM de Prospects — Sossego Urbano

Primeira versão visual e funcional do CRM de prospecção. Abra `index.html` no navegador para testar.

## Esta versão inclui

- Cadastro de nome, telefone, status e próximo contato;
- Follow-ups com histórico por prospect;
- Visões “Ligar hoje” e “Atrasados”;
- Dashboard com indicadores e pipeline;
- Layout responsivo para celular e computador.

## Dados

Nesta prévia, os dados ficam salvos somente no navegador utilizado (`localStorage`). Antes da publicação para a equipe, a próxima etapa é conectar Supabase para login e dados compartilhados.

## Publicação no GitHub Pages

1. Crie um repositório, por exemplo `crm-prospects-sossego-urbano`.
2. Envie os três arquivos desta pasta para a raiz do repositório.
3. Em **Settings → Pages**, escolha **Deploy from a branch**, branch `main` e pasta `/(root)`.
4. Salve e aguarde o link de publicação.
